反应机理 理解参数为什么这样设

酸性条件下，Fe²⁺ 催化 H₂O₂ 分解产生氧化能力极强的羟基自由基（HO·），HO· 攻击亚甲基蓝（MB）分子使其发色基团破坏、蓝色褪去。主要反应：

  • Fe2+ + H2O2 → Fe3+ + HO· + OH−(1) 产生 HO· 的主反应
  • Fe3+ + H2O2 → Fe2+ + HOO· + H+(2) Fe²⁺ 缓慢再生
  • Fe2+ + HO· → Fe3+ + OH−(3) Fe²⁺ 过量时清除 HO·
  • Fe3+ + HOO· → Fe2+ + O2 + H+(4)
  • Fe2+ + HOO· → Fe3+ + HO2−(5)
  • HO· + H2O2 → HOO· + H2O(6) H₂O₂ 过量时清除 HO·
  • HOO· + H2O2 → HO· + H2O + O2(7)
  • H+ + HO· + Fe2+ → H2O + Fe3+(8) pH 过低时清除 HO·

为什么最佳条件脱色约 10 s？

HO· 生成速率 ≈ k₁·c(Fe²⁺)·c(H₂O₂)，k₁ ≈ 63 L·mol⁻¹·s⁻¹（25 ℃）。中心条件 c(Fe²⁺) = 0.20 mmol/L、c(H₂O₂) = 3.0 mmol/L 时，约 10 s 可使 MB 褪去 90%，脱色过程肉眼可完整观察。

Fe²⁺ 为什么不是越多越好？

Fe²⁺ 与 MB 近似化学计量（0.20 vs 0.156 mmol/L）。低投加量组 Fe²⁺ 耗尽后脱色不完全（见表 3 模拟结果）；过量 Fe²⁺ 则按式 (3) 清除 HO·，且残留 Fe³⁺ 使溶液泛黄。

pH 为什么是决定性因素？

pH 升高抑制式 (1) 并促使铁生成 Fe(OH)₃ 絮体，pH 6 以上几乎不反应；pH 过低则 H⁺ 按式 (8) 清除 HO·。最适 pH 在 3 附近——试试把 pH 滑块从 3 拖到 5 再观察。

HO· 去哪儿了？

HO· 寿命仅约 10⁻⁹ s，产生后瞬间被 MB（k ≈ 10¹⁰ L·mol⁻¹·s⁻¹，扩散控制）、H₂O₂、Fe²⁺ 竞争捕获。50 mg/L MB 对 HO· 的捕获份额约 0.9，这正是脱色灵敏的原因。

操作与安全提示

  1. 30% H₂O₂ 具强腐蚀性和强氧化性，配制工作液须戴手套与护目镜，溅到皮肤立即用大量清水冲洗；工作液避光、现配现用。
  2. 稀释硫酸必须「酸入水」并搅拌；Fe²⁺ 母液须酸化配制、现配现用，出现浑浊絮状即弃用重配。
  3. 各烧杯液体加入总量不超过 5.5 mL（约体系的 5%），浓度按 100 mL 反应体积计算。
  4. 脱色时间以肉眼刚好观察不到蓝色为准，同一人、同一背景判读；快于 3 s 记为「<3」。
  5. 取样 2.00 mL 后先加 0.1 mL Na₂SO₃ 淬灭液终止反应，再定容至 25 mL（稀释 12.5 倍）于 664 nm 测定；样液泛黄时滴加 1～2 滴 0.05 mol/L 稀 H₂SO₄ 至澄清。
  6. 废液含铁离子与残余 H₂O₂，倒入指定废液桶集中处理。
